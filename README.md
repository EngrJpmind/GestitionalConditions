# 📄 PROJECT DESCRIPTION

The **Gestational Conditions: Bleeding During Pregnancy** website is an educational web project developed using **HTML, CSS, and JavaScript**.

This project focuses on providing information about different causes of bleeding during pregnancy across the three trimesters.

The website includes:

* Introduction to pregnancy care
* Educational video (infomercial)
* Trimester-based topic navigation
* Information about:

  * Miscarriage
  * Ectopic Pregnancy
  * Gestational Trophoblastic Disease
  * Premature Cervical Dilation
  * Placenta Previa
  * Abruptio Placenta
* Group contribution section
* Interactive navigation using JavaScript

This project was created as an academic requirement and serves as an informational prototype website.

⚠️ This website is for educational purposes only and is not a substitute for professional medical advice.

# 🩺 Gestational Conditions – Bleeding During Pregnancy

## 📌 Overview

This project is an educational website developed using:

* HTML5
* CSS3
* JavaScript

It focuses on providing awareness and information about **bleeding during pregnancy** across different trimesters.

⚠️ This is a school project and not an official medical website.

---

## 🎯 Purpose

The main goal of this website is to:

* Educate users about common causes of bleeding during pregnancy
* Organize information based on trimester
* Promote awareness for maternal health
* Demonstrate web development skills
